データ構造画面 操作手順

実行データで使用する項目の設計図を作ります。値は「データ管理」で入力します。

データ構造画面です。サイドバーの「データ構造」から開き、実行データで使用する項目と階層を設計します。
変更前の確認：既存項目の名前・型・階層を変えると、イベントのデータリンクや保存済みデータに影響します。先に「JSON 入出力」から「JSON を出力」を選んでバックアップしてください。

ボタンの説明

ボタン操作内容注意
追加 → フィールド追加通常項目の選択時は同じ階層の直後へ、object/list の選択時はその配下の末尾へ追加します。未選択時は最上位の末尾へ追加します。
追加 → 子フィールド追加選択中の object/list の末尾へ子項目を追加します。text、number、boolean では使用できません。
編集項目名や型を変更します。選択した項目が対象です。
フィールド削除選択項目と配下の項目を削除します。イベントで使用していないか確認します。
上へ／下へ単一選択では隣接位置へ移動します。Ctrl／Shift の複数選択では各選択ブロックの相対順を維持し、親の先頭／末尾に接する連続選択をまとめて親構造の外へ移動できます。object/list は配下を含む構造全体で移動し、親子を同時選択した場合は親だけを処理します。
Ctrl+C／Ctrl+V選択した複数フィールドを表示順のまま、配下構造ごと複製します。貼付け先の同一階層で重複しない名称が自動設定されます。
ドラッグ項目の順番や階層を変更します。Ctrl／Shift で選んだ複数項目も、相対順のまま一括移動できます。object/list の行中央へドロップすると選択一式を配下へ移動し、行の上側／下側へドロップすると同じ階層の前／後へ移動します。
／object/list 配下の項目を一括して展開または折りたたみます。配下を持つ項目がない場合は使用できません。＋は「すべて展開」、－は「すべて折りたたむ」です。ボタンは次に実行される操作のアイコンへ自動的に切り替わります。
JSON 入出力 → JSON を出力現在のデータ構造をバックアップします。大きな変更の前に実行します。
JSON 入出力 → JSON を読み込むJSON の構造を編集中の画面へ読み込みます。内容を確認して「保存」を押すまでデータベースには確定されません。
Template 操作 → 新規複数の PCL で再利用する object 構造を作成します。Template は常に構造体です。Template 自体を list としては定義しません。
Template 操作 → 編集／削除選択した Template の名称変更または削除を行います。PCL で使用中の Template は削除できません。
保存共通構造と Template 定義を保存します。Template の変更は、その Template を追加済みの全 PCL に自動反映されます。
一覧の状態：階層表は初回だけ折りたたんで表示します。構造の編集、移動、再読込後は選択行と展開／折りたたみ状態を保持します。

項目を追加する

手順 1　追加位置を選びます。通常項目を選ぶとその直後、object/list を選ぶとその配下、未選択では最上位の末尾が追加先になります。
手順 2　追加 から「フィールド追加」を選びます。選択した object/list の配下へ明示的に追加する場合は「子フィールド追加」を選びます。
手順 3　フィールド名とデータ型を設定し、OK を押します。
手順 4　必要な項目を追加したら、保存 を押します。
完了確認：データ管理画面を開き、追加した項目と既存データの値を確認します。構造変更前のデータには新しい項目値が保存されていない場合があります。

Template を作成・更新する

手順 1　左側の Template 操作 から「新規」を選び、Template 名を入力します。
手順 2　作成した Template を選び、右側で通常項目と同じように子フィールドを追加します。
手順 3　保存 を押します。
手順 4　定義を変更した場合は「データ管理」で追加済み PCL を確認します。
自動同期：同名フィールドの入力値は保持されます。追加フィールドは型ごとの既定値で作成され、定義から削除したフィールドは追加済み Template 実体からも削除されます。最上位と list 内のどちらの実体も同期対象です。
Template と list：Template は常に1件分の object です。複数件を扱う場合は、データ管理画面で通常の list を選び、その list の中へ Template を必要な件数だけ追加します。

ドラッグで階層を変更する

手順 1　移動する項目をドラッグします。
手順 2　object/list の中へ移す場合は対象行の中央へ、同じ階層で並べ替える場合は対象行の上側または下側へドロップします。
手順 3　最上位へ戻す場合は、最上位項目の前後へドロップします。
移動できない場合：同じ階層に同名項目がある場合や、親項目を自分自身の子孫へ入れようとした場合は移動できません。
未保存の変更：保存前に別画面へ移動するかアプリを閉じると、保存／破棄／キャンセルを選ぶ確認画面が表示されます。キャンセルすると現在の画面に留まります。

型の選び方

text氏名、コード、URL などの文字。
number数量、金額などの数値。
booleanはい／いいえ、ON／OFF。
object住所など、複数項目をまとめるグループ。
list商品明細など、0件以上繰り返す項目。

object を Excel の別シートへ出力する

手順 1　別シートへ分ける object を選択し、編集 を押します。
手順 2　「Excel 別シート出力」を有効にします。データが空のときにシートを作らない場合は「空時省略」も有効にします。
手順 3　OK を押し、構造画面で 保存 を押します。
設定できる場所：別シート出力は object だけに設定できます。すでに別シート出力される object の配下へ重ねて設定することはできません。
安全な作業順：JSON を出力 → 構造を編集 → 保存 → 実行データを確認。
