データ管理画面 操作手順

左側で実行1回分のデータを選び、右側で各項目の値を編集します。

データ管理画面です。データ名と概要は左側一覧で、階層項目の値は右側で編集します。
画面の見方：左側の1行が実行1回分のデータです。名称と概要は「編集」で変更し、右側で選択中データの値を編集します。

左側のボタン

ボタン操作内容注意
新規名称と概要を指定して空のデータを1件作ります。作成後、右側で値を入力します。
編集選択データの名称と概要を変更します。データ内容と実行グループは変わりません。
複製選択中のデータをコピーします。似たデータの作成に使います。
削除選択データを削除します。確認画面の対象名を確認します。

右側の操作

画面上の表示操作内容注意
値を編集選択した text、number、boolean の値を編集します。値列のダブルクリックでも編集できます。編集後は「保存」を押します。
リスト操作▼ → リスト項目を追加選択した list に空の項目または構造付き項目を追加します。追加後は「保存」を押します。
リスト操作▼ → リスト項目を削除選択した [1]、[2] などのリスト項目を削除します。削除後は「保存」を押します。
／データ内容の object/list 配下を一括して展開または折りたたみます。＋は「すべて展開」、－は「すべて折りたたむ」です。
データ入出力▼ → JSON を出力全実行データを JSON ファイルへ出力します。バックアップに使用します。
データ入出力▼ → JSON を読み込むJSON ファイルから全実行データを復元します。現在の全データが置き換わります。
データ入出力▼ → Excel を出力全実行データを Excel ファイルへ出力します。バックアップや一括編集に使用します。
データ入出力▼ → Excel を読み込むExcel ファイルから全実行データを復元します。現在の全データが置き換わります。
保存右側で編集中の1件を保存します。値、リスト項目の追加・削除を確定します。
保存タイミング：右側の値編集、リスト項目の追加・削除は「保存」で確定します。未保存のまま別データや別画面へ移動するかアプリを閉じると、保存／破棄／キャンセルを選ぶ確認画面が表示されます。
すぐに反映される操作：新規、編集、複製、削除、JSON／Excel 読込は操作確定時にデータベースへ反映されます。

データを1件登録する

手順 1　新規 を押し、名称と概要を入力します。
手順 2　作成したデータを左側で選択します。
手順 3　右側の「値」列をダブルクリックし、値を入力します。
手順 4　list が必要な場合は list 行を選び、リスト操作▼ から項目追加を選びます。
手順 5　保存 を押し、「保存しました」を確認します。
手順 6　基本情報を変更する場合は左側で対象を選び、編集 を押します。
完了確認：保存後に別データへ切り替えて戻り、入力値が保持されていることを確認します。

Excel で一括更新する

手順 1　右側の データ入出力▼ から「Excel を出力」を選び、出力したファイルをひな形として編集します。
手順 2　列名を変えずに値を編集して保存します。
手順 3　右側の データ入出力▼ から「Excel を読み込む」を選び、ファイルと復元件数を確認します。
出力ファイルの見方：すべてのセルは左揃えです。階層型の列見出しは、上位階層を濃い青、下位階層を順に明るい青で表示します。結合された見出し名と列順は変更しないでください。
重要：JSON 読込と Excel 読込は、どちらも追加ではなく全件置換です。現在データは先に出力してください。
読込後の確認：件数、データ名、概要、list の件数を確認し、「実行管理」で今回実行と実行グループを確認してください。
